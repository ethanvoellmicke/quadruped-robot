# 12-DOF Quadruped Robot

A custom quadruped robot designed and built from scratch using ROS 2, C++, Arduino, URDF, inverse kinematics, and custom hardware.

## Features

- 12 DOF quadruped
- ROS 2 Jazzy
- RViz visualization
- C++ gait controller
- Custom inverse kinematics
- Arduino firmware
- PCA9685 servo controller
- Physical prototype

## Repository Structure

```
ros2/
    ROS 2 visualization and kinematics

arduino/
```
